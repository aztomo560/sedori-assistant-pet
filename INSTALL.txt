せどり助手 — Codexデスクトップアプリ用ペット

茶色のたぬきに、紺の帽子とエプロン。段ボールとバーコードスキャナーを持ったペットです。
作業中・確認待ち・レビュー・エラーなど、9種類の動きを収録しています。

【必要なもの】
ペット機能が使えるCodexデスクトップアプリ。
このZIPに完成した画像が入っているため、画像生成や作成用スキルの導入は不要です。
以下はWindowsの標準保存先を使用する手順です。

【追加する手順】
1. ダウンロードしたZIPを右クリックし、「すべて展開」を選びます。
2. WindowsキーとRキーを押し、次の文字を入力してEnterを押します。
   %USERPROFILE%\.codex
3. 開いた場所に pets フォルダーがなければ、新しく作成します。
4. ZIPから展開した sedori-assistant フォルダーを、その pets の中へコピーします。
   追加後の位置は次のようになります。
   %USERPROFILE%\.codex\pets\sedori-assistant\pet.json
   %USERPROFILE%\.codex\pets\sedori-assistant\spritesheet.webp
5. Codexで、左下のプロフィールアイコン → 設定 →「Mini と Pet」を開きます。
6. 「自分のPet」の横にある更新ボタンを押し、「せどり助手」を選びます。
7. Alt + Windows + P を押すと、ペットを表示できます。

【非表示にする】
ペットを右クリックし、非表示（Hide）を選びます。
再表示は、Codexを起動した状態で Alt + Windows + P です。

【注意】
・同じ名前の sedori-assistant フォルダーが既にある場合は、上書きする前に既存フォルダーを別の場所へ保管してください。
・CODEX_HOMEを変更している方は、その保存先の pets フォルダーを使います。
・設定名やショートカットは、アプリのバージョンや個別設定により異なる場合があります。
・作業状態の判定・切り替えはCodexが行います。正確な進捗率や残り時間を表示する機能はありません。
・完成ファイルの形式と全57コマの画像・動きは検証済みです。制作者のWindowsアプリで一覧への読み込みを確認しています。他のPCでの実機確認はしていません。
・ペットの非表示では本体データは削除されません。

【同梱ファイル】
sedori-assistant/pet.json              名前・画像ファイル名などの設定
sedori-assistant/spritesheet.webp      透明背景のアニメーション画像
はじめに.txt                          この説明

個別のPCの作業ログ・インストール記録・APIキーは同梱していません。
